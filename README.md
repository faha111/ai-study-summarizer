# AI Study Summarizer 🚀

A lightweight, responsive web application designed for students to convert long lecture notes, articles, and textbooks into quick, digestible summary bullet points.

## ✨ Features
- **Instant Processing:** Input raw study notes and receive key summary points in seconds.
- **Clean UI:** Modern dark-mode interface built with Tailwind CSS.
- **Client-Side Processing:** Rapid extraction with zero server delay.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS
- **Logic:** Modern JavaScript (ES6)
